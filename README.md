# 问题记录 - 个人问题记录与提醒应用

一款面向个人使用的手机应用，支持语音/手动输入问题，按种类和时间自动分类，并提供智能提醒功能。

## 功能特性

- 🎤 **语音输入** - 长按麦克风按钮，实时语音识别转文字
- ⌨️ **手动输入** - 文本框输入，支持多行文本
- 🏷️ **智能分类** - 按问题种类（工作/生活/学习/健康/财务）自动分类
- 📅 **时间分组** - 自动按日期（今天/昨天/本周/本月/更早）分组
- ⏰ **定时提醒** - 为问题设置具体提醒时间
- 🔄 **重复提醒** - 支持每日/每周/每月重复
- ✅ **完成归档** - 已解决的问题归档到历史记录
- 🔍 **搜索过滤** - 按关键词、标签、时间范围筛选

## 技术栈

- **框架**: Flutter 3.x
- **语言**: Dart
- **状态管理**: Riverpod
- **本地数据库**: SQLite (sqflite)
- **语音识别**: speech_to_text
- **本地通知**: flutter_local_notifications

## 运行步骤

### 1. 安装 Flutter

确保已安装 Flutter SDK（版本 >= 3.0.0）：

```bash
flutter doctor
```

### 2. 获取依赖

```bash
cd question_reminder_app
flutter pub get
```

### 3. 运行应用

**Android:**
```bash
flutter run
```

**iOS (需要 Mac):**
```bash
flutter run -d ios
```

## 权限说明

应用需要以下权限：

- **麦克风权限** - 用于语音识别输入
- **通知权限** - 用于发送提醒通知
- **网络权限** - 语音识别需要联网使用

首次使用语音输入和设置提醒时，系统会弹出权限请求，请点击允许。

## 使用指南

### 添加新问题

1. 点击首页右下角的 **"新建"** 按钮
2. 选择输入方式：
   - **语音输入**: 长按麦克风图标说话
   - **手动输入**: 在文本框中输入内容
3. 选择问题类别（工作/生活/学习/健康/财务）
4. 设置优先级（普通/重要/紧急）
5. 可选：设置提醒时间和重复规则
6. 可选：设置截止日期
7. 点击 **"保存"**

### 管理问题

- **完成问题**: 在问题卡片上左滑，点击"完成"
- **删除问题**: 在问题卡片上左滑，点击"删除"
- **查看详情**: 点击问题卡片进入详情页

### 分类浏览

点击底部导航栏的 **"分类"** 标签，可以按类别浏览问题。

### 搜索

点击首页右上角的搜索图标，输入关键词搜索问题。

## 注意事项

1. **语音识别**需要联网使用（基于云端识别服务）
2. **通知权限**需要在系统设置中开启，否则无法收到提醒
3. 部分 Android 厂商对后台通知有限制，如遇问题请检查系统设置
